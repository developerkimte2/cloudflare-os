## 項目 1. 取り込み結果の判定 AI を実際のモデルにする (P1)

`AnswerView` が独自にやっている「実際のモデルがあればそれ、無ければ設定上のモデル」の分岐を `AiAttribution` に吸収し、取り込み結果・回答・案件詳細の 3 か所を同じ部品・同じ表記にする。

### 修正

1. `packages/gatekeeper-sales/app/components/AiAttribution.tsx`:
   ```tsx
   export function AiAttribution({ ai, actual }: { ai: WhoAmI["ai"]; actual?: string }) {
     // `actual` は AIDecision / AIContextSnapshot / AnswerResult に残った「実際に判定したモデル」
     // ("provider/model")。無い (未処理・失敗) ときだけ設定上のモデルを出す。
     const label = actual ?? (ai.configured ? `${ai.provider}/${ai.model}` : "未設定");
   ```
